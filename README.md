# OptimusPass // Web-Based Event Management & Digital Pass Generator

An automated web application designed for seamless event registration, real-time client-side form validations, and digital pass generation. Built for Semester III Field Projects (FP).

## 🚀 Key Features
- **3D Interactive Hero Canvas:** Dynamic rotating globe powered by Cobe WebGL.
- **Client-Side Form Validations:** Strict regex checks for names, email addresses, 10-digit mobile numbers, and ticket allocations.
- **Responsive UI:** Dark-mode glassmorphism interface built with Bootstrap 5.
- **Relational Database Backend:** PHP & MySQL schema for persistent user and pass record storage.

## 🛠️ Tech Stack
- **Front-End:** HTML5, CSS3, JavaScript (ES6+), Bootstrap 5, Cobe 3D
- **Back-End:** PHP
- **Database:** MySQL (Relational DBMS)
- **Deployment:** GitHub Pages (Front-End) & Local XAMPP (Full Stack)
